# Мой живой аквариум

Уютный 3D-симулятор аквариума и акватеррариума для Android (three.js + Capacitor). Работает полностью офлайн, без аккаунта, рекламы и встроенных покупок.

## Возможности игры
- **27 видов обитателей с 3D-моделями и реалистичным половым диморфизмом (♂/♀):**
  - 20 видов рыб: гуппи, неон голубой, данио-рерио, эндлер, кардинал, вишнёвый барбус, расбора клинопятнистая, меченосец, пецилия, моллинезия, жемчужный гурами, лялиус, петушок, скалярия, дискус, золотая рыбка, апистограмма, радужница Боэсмана, тернеция, тетра Аманда.
  - 3 вида донных сомиков: анциструс, коридорас, отоцинклюс.
  - 4 обитателя акватеррариума: пресноводный крабик, огненнобрюхий тритон, мускусная черепаха и илистый прыгун.
- **Энциклопедия видов («О виде в природе»):** родина и ареал, природная среда обитания, образ жизни, отличия самца и самки и интересные факты для каждого вида.
- **Размножение и жизненный цикл:**
  - Настраиваемые ухаживание с сердечками, размножение (живородящие с беременностью и икромечущие с 3D-кладками икринок), наследование окраски от родителей, история семьи и поколений, автоматическая защита от перенаселения.
  - Стадии роста (малёк → молодая → взрослая → пожилая), ускоренный рост мальков в Выростном отсеке, настраиваемый срок жизни рыбок (от 1 недели до 1 года или ∞ навсегда) с Памятным альбомом.
- **5 аквариумов:** 60 л, 120 л, панорамный 200 л, Акватеррариум с берегом и сушей и Выростной отсек 30 л для мальков — с быстрым переключением, пересадкой питомцев и регулировкой температуры нагревателя (18–30 °C).
- **Уход и мини-игры уборки:** губка для стекла, скребок для стойкого налёта, сифон для грунта, промывка губки фильтра, сачок с подсветкой остатков корма на дне, подмена 20% воды, 3 вида корма (хлопья, гранулы, донные таблетки) и компактная боковая панель инструментов.
- **Украшения и растения:** камни, коряги, гроты, керамические укрытия, затонувший кораблик, замок с башнями, античные колонны, сундук с сокровищами и пузырьками, каменная пагода, валлиснерия, анубиас и мох.
- **Атмосфера и уведомления:** замкнутая уютная комната, смена дня/вечера/ночи, подводные лучи света, реальные записанные звуки воды, пузырьков и спокойного фортепиано (CC0), локальные Android-уведомления об уходе, режим наблюдения, фоторежим с альбомом, задания, комфортный и творческий режимы.

## Сборка APK через GitHub Actions
1. Загрузи содержимое проекта в репозиторий на GitHub (включая скрытую папку `.github`).
2. Открой вкладку **Actions** → **«Сборка APK»** → **Run workflow**.
3. Скачай готовый артефакт `MoyZhivoyAkvarium-apk` и установи `MoyZhivoyAkvarium.apk` на телефон.

## Локальный запуск в браузере
`cd www && python -m http.server 8080` → открыть `http://localhost:8080`
